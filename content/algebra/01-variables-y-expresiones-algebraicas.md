## Primero, la intuición

Una variable representa una cantidad que puede cambiar o cuyo valor aún no conoces. Una expresión combina variables, números y operaciones. Una ecuación añade una igualdad entre dos expresiones.

Para evaluar una expresión, sustituye la variable y respeta el orden de operaciones. Los términos semejantes tienen la misma parte literal: puedes sumarlos combinando sus coeficientes.

:::idea
Una variable representa una cantidad. Una expresión combina números, variables y operaciones; una ecuación afirma que dos expresiones son iguales.
:::

:::ejemplo
Si x = 4, la expresión 3x + 2 vale 3·4 + 2 = 14. Además, 3x + 2x = 5x, pero 3x + 2 no se simplifica a 5x.
:::
